Assignment: Personal Portfolio Page

This project is a single-page personal portfolio created using only
HTML and CSS.

It includes:
- A navigation bar
- A hero section
- An About Me section
- A Skills section
- A contact form
- A footer

The project uses semantic HTML, Flexbox and an external stylesheet.
No JavaScript or CSS framework was used.
